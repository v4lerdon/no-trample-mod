# No Trampling

Fabric mod that prevents farmland from being trampled into dirt.

## English

### Features
- Farmland never turns into dirt when entities fall on it.
- Lightweight mixin; no configs needed.

### Compatibility
- Loader: Fabric
- Minecraft: 1.26.x (see `fabric.mod.json` for exact range)
- Java: 25+

### Install
1. Install Fabric Loader and Fabric API for your Minecraft version.
2. Put the built JAR into your `mods` folder.

### Build
```bash
./gradlew build
```
The JAR will be in `build/libs`.
